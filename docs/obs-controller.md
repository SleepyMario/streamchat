# OBS Controller moved

OBS Controller is now maintained in [SleepyMario/obs-controller](https://github.com/SleepyMario/obs-controller). Its independent service owns the controller UI, OBS commands, Windows companion, bitrate helper and camera recovery. Streamchat continues supplying chat and subtitle-worker APIs.

The deployed HTTPS address remains https://sleepymario.com/obs/ over WireGuard.
